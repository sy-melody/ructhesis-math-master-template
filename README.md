# 中国人民大学数学学院硕士论文 LaTeX 模板

本项目为 **中国人民大学数学学院硕士论文 LaTeX 模板（非官方）**，主要适配数学学院**在职硕士论文**的排版与格式要求。

模板最初来源于本人在数学学院导师提供的原始 LaTeX 模板，在此基础上，结合数学学院在职硕士论文模板要求的具体字号、页面与前置材料要求，对模板进行了整理与扩展，补充并规范了以下内容：

- 封面页  
- 学位论文基本信息表  
- 学位论文使用授权说明页  

如为**全日制研究生**，可根据学院当年发布的具体要求，对部分设置进行微调，或注释掉不需要的页面。

---

## 模板特点

- 使用 **XeLaTeX** 编译，支持中英文混排  
- 单主文件结构，便于 LaTeX 初学者理解与修改  
- 从摘要开始，正文中包含示例性填充文字，结合**计算数学专业**的常见写作结构  
- 示例中穿插了常见 LaTeX 功能的使用案例（公式、定理环境、引用等）

模板正文中的填充文字主要用于**占位与写作示例**。  
在撰写示例内容过程中，**使用过生成式人工智能进行辅助**，仅作为结构与表达参考，请勿直接用于正式论文内容。

---

## 编译方式（Quick Start）

- **推荐编译引擎**：`XeLaTeX`
- **主文件**：`main.tex`
- **不支持**：`pdflatex`

你可以选择以下任一方式使用本模板：

### 方式一：在线编辑（推荐）
- 上传整个模板压缩包（zip格式）至 [TeXPage](https://www.texpage.com) 后在线编辑与编译

### 方式二：本地编译
- 安装 TeX Live / MacTeX
- 使用 `xelatex main.tex` 进行编译
